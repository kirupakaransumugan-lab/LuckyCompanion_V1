# Lucky Companion

A small animated desktop companion for Windows, built with Electron + React + Vite.
Original concept and code — not affiliated with Book My Luck.

## Setup

```
npm install
```

## Run in development

```
npm run dev
```

This starts the Vite dev server and opens the Electron window pointed at it.

## Build a Windows installer

```
npm run dist
```

The installer is created in the `release/` folder.
